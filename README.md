# Meu-Projeto-Teste
 Este formulário é um (formulário de cadastro), onde nele pede o 'nome', 'sobrenome' e 'país'. Se clicar em enviar sem ter preenchido os campos ou deixar um ou dois faltando para enviar, aparecerá na tela "Preencha todos os campos antes de enviar.". Mas se preencher todos os campos antes de enviar e enviar, aparecerá na tela "Formulário enviado com sucesso".
